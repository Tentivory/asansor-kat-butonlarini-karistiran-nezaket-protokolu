# Asansör Kat Butonlarını Karıştıran Nezaket Protokolü

> Bu yazılım bir şaka değildir. Şaka gibi durması, protokolün ciddiyetinin bir parçasıdır.

## Resmi amaç

Vatandaş asansörde bir kata basar. Kabin bu talebi *değerlendirir*. 
Değerlendirme sonucu genellikle başka bir kattır. 
Ardından özür dilenir. Özür resmi, uzun ve biraz kırıcıdır.

Bu proje, yanlış kata basmanın toplumsal bir mesele olduğunu kabul eder.

## Neden vardır?

Çünkü:

1. Asansörler çok uzun sürece fazla güvenilir olmuştur.
2. İnsanlar butona basmadan önce düşünmemektedir.
3. Nezaket, yazılı protokol olmadan yaşayamaz.
4. Bir yazılımın işe yaramaması, onun anlamsız olduğu anlamına gelmez.

## Kurulum

Python 3 yeterlidir. Bağımlılık yoktur. Bu bir özelliktir.

```bash
git clone https://github.com/Tentivory/asansor-kat-butonlarini-karistiran-nezaket-protokolu.git
cd asansor-kat-butonlarini-karistiran-nezaket-protokolu
python3 protokol.py
```

## Kullanım örneği

```
Hangi kata gitmek istiyorsunuz? (örn: 5, -1, 0): 7
Muhterem yolcu, butona temastan evvel niyetinizi teyit etmeniz gerekirdi.
Kapılar kapanıyor. Nezaket protokolü devrede.
  ... 1. kat
  ... 2. kat
  ... 3. kat
Talep: 7. kat
Karar: 3. kat
(Gerekçe belgesi henüz yazılmamıştır.)
```

Yüzde on sekiz ihtimalle doğru kata gidersiniz. 
Bu oran bilimsel değildir ama resmi görünmektedir.
